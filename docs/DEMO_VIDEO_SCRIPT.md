# Grounded Route — Demo Video Shooting Script

Target: **< 3 minutes**, public YouTube, **with audio** (voiceover required by the rules).
Goal: a judge believes in the first 25 seconds that a human and an agent are improving the same live workspace, and the human keeps final authority.

**Live URL:** https://raffieeey.github.io/grounded-route/
**Repo:** https://github.com/raffieeey/grounded-route (public, MIT)

---

## Setup (before recording)

1. Use a clean browser profile, **390×844-ish mobile or a tidy desktop window** — desktop is fine and easier to read; mobile shows the fold discipline. Pick one and stay consistent.
2. Have the live URL loaded, fresh session (click "Clear current session" if needed).
3. Open it in **ChatGPT's in-app browser** for the agent portion (native WebMCP) — OR Chrome with the WebMCP flag + your MCP client ready.
4. Screen recorder on, mic on, notifications off. Record in one unbroken take if you can; cuts are allowed but the agent-acts beat must be unedited.

## Recording tips

- The **0:20–0:50 beat is the whole video.** If nothing else lands, that must. Practice it twice before recording.
- Talk while the agent works — dead air during the sweep kills the momentum.
- If the ChatGPT-browser agent is slow, don't re-record mid-take; narrate ("it's inspecting the route context now…") — confidence reads better than perfection.
- Upload as **public** (not unlisted), add the repo + live URL in the description, and a title like "Grounded Route — WebMCP Challenge: human and agent on the same live map".
